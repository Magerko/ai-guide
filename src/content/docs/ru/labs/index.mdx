Лабораторная (по-английски раздел называется Agent Labs) — это описание эксперимента. Одну и ту же задачу получают разные AI-программы, каждая выполняет её по нескольку раз, а я записываю, что получилось: в каких условиях, насколько результат соответствует заранее записанным требованиям и чего из этого заключить нельзя. Победителей я не объявляю: по нескольким попыткам на одной задаче их не назовёшь.

Здесь одна лабораторная — <a href={pageUrl('ru', 'labs/01-personal-site')}>«Личный сайт: одна задача — Claude Code и Codex»</a>. Два AI-агента — программы, которые не только отвечают, но и сами создают файлы на компьютере, — получили одно и то же задание: сделать сайт из трёх страниц для репетитора. Каждый выполнил его по два раза.

Она для тех, кому интересно не «какой AI лучше», а как такие программы ведут себя на настоящей задаче и как проверить их работу самому. Читать её лучше после уроков, начиная с <a href={pageUrl('ru', 'basics/01-what-is-ai')}>«Что такое AI и языковая модель»</a>: она опирается на первый, второй и четвёртый, а остальное объясняется прямо в ней. Ничего устанавливать для этого не нужно.
