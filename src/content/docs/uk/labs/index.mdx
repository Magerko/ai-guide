Лабораторна (англійською розділ називається Agent Labs) — це опис експерименту. Те саме завдання отримують різні програми зі ШІ (штучний інтелект; англійською AI), кожна виконує його по кілька разів, а я записую, що вийшло: за яких умов, наскільки результат відповідає наперед записаним вимогам і яких висновків із цього робити не можна. Переможців я не оголошую: за кількома спробами на одному завданні їх не визначиш.

Тут одна лабораторна — <a href={pageUrl('uk', 'labs/01-personal-site')}>«Особистий сайт: одне завдання — Claude Code і Codex»</a>. Два ШІ-агенти — програми, які не лише відповідають, а й самі створюють файли на комп’ютері, — отримали те саме завдання: зробити сайт із трьох сторінок для репетиторки. Кожен виконав його двічі.

Вона для тих, кому цікаво не «який ШІ кращий», а як такі програми поводяться на справжньому завданні і як перевірити їхню роботу самому. Читати її краще після уроків, починаючи з <a href={pageUrl('uk', 'basics/01-what-is-ai')}>«Що таке ШІ і мовна модель»</a>: вона спирається на перший, другий і четвертий, а решту пояснено прямо в ній. Нічого встановлювати для цього не треба.
